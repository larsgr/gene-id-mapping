# Claude Code Project Configuration

This directory contains project-specific configuration and extensions for Claude Code.

## Directory Structure

- `skills/` - Custom skills that extend Claude Code's capabilities for this project
  - `session-end/` - Skill for documenting AI sessions following project workflow

## What Gets Committed

Only the `skills/` directory is tracked in git. Other files in `.claude/` are local configuration:
- `settings.local.json` - Local user settings (not committed)
- Other temporary files generated by Claude Code (not committed)

## Skills

### session-end

The `/session-end` skill automates the documentation workflow at the end of AI sessions:
- Prompts for session information
- Updates docs/AI-usage.md
- Updates relevant detailed task log in docs/
- Suggests commit message
- Maintains consistency across documentation

See `skills/session-end/SKILL.md` for details.

## Usage

Skills are automatically loaded by Claude Code when working in this project. Users can invoke the session-end skill by typing `/session-end` or by saying "document this session".
